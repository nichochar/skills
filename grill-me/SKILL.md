# Grill Me

Ask the user as many questions as you need to get a strong shared understanding of a project or task.

If you can uncover answers by doing research autonomously, do so.

The goal is to make sure you can build a strong project description and then hand that over, so that it will get executed with precision.

For each question, provide your recommended answer.
