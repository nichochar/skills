Technical-writing source is MIT licensed; see `LICENSE`.

This skill is from the [cursor/plugins](https://github.com/cursor/plugins) repository, specifically the [pstack](https://github.com/cursor/plugins/tree/main/pstack) plugin by [Lauren Tan](https://x.com/poteto).

The technical-writing skill defines a layered technical-writing standard:
- Diátaxis structure for document modes (tutorial, how-to, reference, explanation)
- Google developer style for sentence construction
- Simplified Technical English (STE) rules for statement clarity
- Global English syntax for unambiguous reading

The skill was originally authored as part of pstack and is used here under the MIT license.
